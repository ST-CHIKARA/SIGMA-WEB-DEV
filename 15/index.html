But Inline CSS is not generally used because it is a repetitive work that we need to do in each element to overcome this we use Internal CSS

We have moved away from the greetings - This is done by using Internal CSS which uses style tags in head below the titles tag

With the help of Internal CSS using the style tag we can do bulk changes or bulk edits in our website as we have to define the type of style we need just once for the specific element and that will apply to all of the elements that are mentioned in Internal CSS

But the problem with this is that it makes our HTML file bulky as in a proper website we need to make many style components and we cant clutter the HTML file with all the CSS we need so to over come that we use External CSS by making a style.css file and link it in HTML file using link tag below the title tag
